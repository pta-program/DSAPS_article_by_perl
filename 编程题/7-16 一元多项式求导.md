## 7-16 一元多项式求导

- **分值：** 20分

## 题目描述

设计函数求一元多项式的导数。

## 输入格式

以指数递降方式输入多项式非零项系数和指数（绝对值均为不超过1000的整数）。数字间以空格分隔。
注意：零多项式用 `0 0` 表示。

## 输出格式

以与输入相同的格式输出导数多项式非零项的系数和指数。数字间以空格分隔，但结尾不能有多余空格。

## 输入样例
```text
3 4 -5 2 6 1 -2 0
```

## 输出样例
```text
12 3 -10 1 6 0
```

## 解题思路

本题采用逐项多项式求导，围绕题目给出的数据结构和约束完成核心计算，并处理边界情况。

## 代码流程说明

1. 读取题目规定的输入数据。
2. 使用逐项多项式求导完成主要处理。
3. 处理边界情况并整理结果。
4. 按指定格式输出结果。

## 代码实现


```python
"""逐项应用 (a*x^b)' = (a*b)*x^(b-1)，常数项导数不输出。"""


def main():
    import sys
    values = list(map(int, sys.stdin.buffer.read().split()))
    result = []
    for coefficient, exponent in zip(values[::2], values[1::2]):
        if exponent != 0:
            result.extend((coefficient * exponent, exponent - 1))
    print(" ".join(map(str, result)) if result else "0 0")


if __name__ == "__main__":
    main()
```
