## 7-20 表达式转换

- **分值：** 25分

## 题目描述

算术表达式有前缀表示法、中缀表示法和后缀表示法等形式。日常使用的算术表达式是采用中缀表示法，即二元运算符位于两个运算数中间。请设计程序将中缀表达式转换为后缀表达式。

## 输入格式

输入在一行中给出不含空格的中缀表达式，可包含`+`、`-`、`*`、`/`以及左右括号`()`，表达式不超过20个字符。

## 输出格式

在一行中输出转换后的后缀表达式，要求不同对象（运算数、运算符号）之间以空格分隔，但结尾不得有多余空格。

## 输入样例
```text
2+3*(7-4)+8/4
```

## 输出样例
```text
2 3 7 4 - * + 8 4 / +
```

## 解题思路

本题采用运算符栈中缀转后缀，围绕题目给出的数据结构和约束完成核心计算，并处理边界情况。

## 代码流程说明

1. 读取题目规定的输入数据。
2. 使用运算符栈中缀转后缀完成主要处理。
3. 处理边界情况并整理结果。
4. 按指定格式输出结果。

## 代码实现


```python
"""运算符栈实现中缀转后缀；数字（含一元负号）作为一个操作数输出。"""


def main():
    import sys
    expression = sys.stdin.readline().strip()
    if not expression:
        return
    priority = {"+": 1, "-": 1, "*": 2, "/": 2}
    operators, output = [], []
    i = 0
    while i < len(expression):
        char = expression[i]
        is_unary = char in "+-" and (i == 0 or expression[i - 1] == "(")
        if char.isdigit() or char == "." or is_unary:
            token = "" if char == "+" else char
            i += 1
            while i < len(expression) and (expression[i].isdigit() or expression[i] == "."):
                token += expression[i]
                i += 1
            output.append(token)
            continue
        if char == "(":
            operators.append(char)
        elif char == ")":
            while operators and operators[-1] != "(":
                output.append(operators.pop())
            if operators:
                operators.pop()
        elif char in priority:
            while operators and operators[-1] != "(" and priority[operators[-1]] >= priority[char]:
                output.append(operators.pop())
            operators.append(char)
        i += 1
    while operators:
        output.append(operators.pop())
    print(" ".join(output))


if __name__ == "__main__":
    main()
```
