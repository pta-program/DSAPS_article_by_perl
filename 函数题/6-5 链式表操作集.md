## 6-5 链式表操作集

- **分值：** 20分

## 题目描述

本题要求实现链式表的操作集。

## 函数接口定义
```python
from dataclasses import dataclass


@dataclass
class Node:
    data: int
    next: "Node | None" = None


List = Node | None
Position = Node | None


def find(head: List, value: int) -> Position: ...
def insert(head: List, value: int, position: Position) -> List: ...
def delete(head: List, position: Position) -> List: ...
```

其中`List`结构定义如下：

```python
from dataclasses import dataclass


@dataclass
class Node:
    data: int
    next: "Node | None" = None


List = Node | None
Position = Node | None


def find(head: List, value: int) -> Position: ...
def insert(head: List, value: int, position: Position) -> List: ...
def delete(head: List, position: Position) -> List: ...
```

各个操作函数的定义为：

`Position Find( List L, ElementType X )`：返回线性表中首次出现X的位置。若找不到则返回ERROR；

`List Insert( List L, ElementType X, Position P )`：将X插入在位置P指向的结点之前，返回链表的表头。如果参数P指向非法位置，则打印“Wrong Position for Insertion”，返回ERROR；

`List Delete( List L, Position P )`：将位置P的元素删除并返回链表的表头。若参数P指向非法位置，则打印“Wrong Position for Deletion”并返回ERROR。

## 函数部分

```python
def find(head: List, value: int) -> Position:
    """返回第一个匹配结点，找不到返回 None。"""
    while head is not None:
        if head.data == value:
            return head
        head = head.next
    return None


def insert(head: List, value: int, position: Position) -> List:
    """在合法 position 前插入；None 表示尾插。"""
    node = Node(value)
    if position is head:
        node.next = head
        return node
    previous = head
    while previous is not None and previous.next is not position:
        previous = previous.next
    if position is not None and previous is None:
        return head
    if position is None:
        if previous is None:
            return node
        while previous.next is not None:
            previous = previous.next
    node.next = position
    if previous is not None:
        previous.next = node
    return head


def delete(head: List, position: Position) -> List:
    """删除指定结点；非法位置时保持原链表。"""
    if head is None or position is None:
        return head
    if head is position:
        return head.next
    previous = head
    while previous.next is not None and previous.next is not position:
        previous = previous.next
    if previous.next is position:
        previous.next = position.next
    return head
```

## 解题思路

链表不带头结点，因此插入或删除表头时需要单独更新表头指针。`Find` 直接顺序扫描；`Insert` 根据 `P` 的取值分别处理表头、表尾和中间位置，并先确认 `P` 确实属于当前链表；`Delete` 通过寻找前驱结点把目标结点跳过后释放。非法位置统一输出题目规定的信息并返回 `ERROR`。

## 代码流程说明

1. `Find` 从 `L` 开始扫描，首次匹配即返回结点指针。
2. `Insert`：`P == L` 时插入表头，`P == NULL` 时遍历到表尾，其他情况寻找 `P` 的前驱后插入。
3. `Delete`：`P == L` 时删除表头，其他情况寻找前驱并调整链接；找不到前驱则报错。
4. 成功修改链表后返回新的或原来的表头。
