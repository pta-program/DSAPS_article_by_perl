## 6-1 单链表逆转

## 裁判测试程序样例
```python
from dataclasses import dataclass


@dataclass
class Node:
    data: int
    next: "Node | None" = None


def reverse(head):
    """裁判程序调用待测函数，并检查原地反转后的两个表头。"""
    previous = None
    current = head
    while current is not None:
        following = current.next
        current.next = previous
        previous, current = current, following
    return previous


def values(head):
    result = []
    while head is not None:
        result.append(head.data)
        head = head.next
    return result


def main():
    import sys
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    dummy = Node(0)
    tail = dummy
    for value in data[1:1 + data[0]]:
        tail.next = Node(value)
        tail = tail.next
    old_head = dummy.next
    new_head = reverse(old_head)
    print(" ".join(map(str, values(old_head))))
    print(" ".join(map(str, values(new_head))))


if __name__ == "__main__":
    main()
```

## 函数部分

```python
def reverse(head: List) -> List:
    """三个指针依次完成后继保存、指向反转和整体前移。"""
    previous = None
    current = head
    while current is not None:
        following = current.next  # 改链前保存未处理部分。
        current.next = previous
        previous, current = current, following
    return previous
```

## 解题思路

使用三个指针从头到尾遍历链表：`prev` 指向已经逆转的部分，`curr` 指向当前结点，`next` 暂存当前结点的后继。每次先保存后继，再把当前结点指向 `prev`，随后三个指针依次向后移动。遍历结束时，`prev` 就是逆转后的表头。时间复杂度为 `O(n)`，空间复杂度为 `O(1)`。

## 代码流程说明

1. 初始化 `prev = NULL`，`curr = L`。
2. 当 `curr` 不为空时，保存 `curr->Next`。
3. 将 `curr->Next` 改为 `prev`，完成当前指针的逆转。
4. 令 `prev = curr`、`curr = next`，继续处理下一个结点。
5. `curr` 为空时返回 `prev`。
