## 6-7 在一个数组中实现两个堆栈

- **分值：** 20分

## 题目描述

本题要求在一个数组中实现两个堆栈。

## 函数接口定义
```perl
# Perl 用哈希/数组引用模拟题目中的结点和容器类型。
use strict;
use warnings;

# push/pop 与 Perl 内置函数同名，调用时使用 &push(...) 和 &pop(...)。
sub create_stack;
sub push;
sub pop;
```

其中`Tag`是堆栈编号，取1或2；`MaxSize`堆栈数组的规模；`Stack`结构定义如下：

```perl
# Stack 是包含 data、top1、top2 和 max_size 的哈希引用。
# top1 从左向右增长，top2 从右向左增长。
```

注意：如果堆栈已满，`Push`函数必须输出“Stack Full”并且返回false；如果某堆栈是空的，则`Pop`函数必须输出“Stack Tag Empty”（其中Tag是该堆栈的编号），并且返回ERROR。

## 裁判测试程序样例
```perl
# 裁判样例：读取操作单词，两个栈共享一个数组。
use strict;
use warnings;

sub print_stack {
    my ( $stack, $tag ) = @_;
    my @values;
    if ( $tag == 1 ) {
        @values = reverse @{ $stack->{data} }[ 0 .. $stack->{top1} ]
          if $stack->{top1} >= 0;
    }
    else {
        @values = @{ $stack->{data} }[ $stack->{top2} .. $#{ $stack->{data} } ]
          if $stack->{top2} < @{ $stack->{data} };
    }
    print "Pop from Stack $tag:", @values ? ' ' . join( ' ', @values ) : '', "\n";
}

sub main {
    my @input = split /\s+/, join '', <STDIN>;
    return unless @input;
    my $size = shift @input;
    my $stack = create_stack($size);
    while (@input) {
        my $operation = shift @input;
        last if lc($operation) eq 'end';
        if ( lc($operation) eq 'push' ) {
            my ( $tag, $value ) = ( shift @input, shift @input );
            print "Stack $tag is Full!\n" unless &push( $stack, $value, $tag );
        }
        elsif ( lc($operation) eq 'pop' ) {
            my $tag = shift @input;
            my $value = &pop( $stack, $tag );
            print "Stack $tag is Empty!\n" if $value == 100_000_000;
        }
    }
    print_stack( $stack, 1 );
    print_stack( $stack, 2 );
}
main();
```

## 输入样例
```text
5
Push 1 1
Pop 2
Push 2 11
Push 1 2
Push 2 12
Pop 1
Push 2 13
Push 2 14
Push 1 3
Pop 2
End
```

## 输出样例
```text
Stack 2 Empty
Stack 2 is Empty!
Stack Full
Stack 1 is Full!
Pop from Stack 1: 1
Pop from Stack 2: 13 12 11
```

## 函数部分

```perl
# 两端栈顶相邻时没有空槽；push 移动对应栈顶写入，pop 移动栈顶取值。
sub create_stack {
    my ($size) = @_;
    return {
        data     => [ (0) x $size ],
        top1     => -1,
        top2     => $size,
        max_size => $size,
    };
}

sub push {
    my ( $stack, $value, $tag ) = @_;
    if ( $stack->{top1} + 1 == $stack->{top2} ) {
        print "Stack Full\n";
        return 0;
    }
    if   ( $tag == 1 ) { $stack->{data}[ ++$stack->{top1} ] = $value }
    else               { $stack->{data}[ --$stack->{top2} ] = $value }
    return 1;
}

sub pop {
    my ( $stack, $tag ) = @_;
    if ( $tag == 1 ) {
        if ( $stack->{top1} == -1 ) {
            print "Stack 1 Empty\n";
            return 100_000_000;
        }
        return $stack->{data}[ $stack->{top1}-- ];
    }
    if ( $stack->{top2} == @{ $stack->{data} } ) {
        print "Stack 2 Empty\n";
        return 100_000_000;
    }
    return $stack->{data}[ $stack->{top2}++ ];
}
```

## 解题思路

让两个堆栈共享同一个数组：堆栈 1 从下标 0 向右增长，堆栈 2 从下标 `MaxSize - 1` 向左增长。初始时 `Top1 = -1`、`Top2 = MaxSize`；当 `Top1 + 1 == Top2` 时，两边栈顶相邻，数组没有剩余空间。这样可以动态共享未使用的空间。

## 代码流程说明

1. `CreateStack` 分配栈结构和数组，初始化两个栈顶。
2. `Push` 先检查两个栈顶是否相邻；未满时根据 `Tag` 移动对应栈顶并保存元素。
3. `Pop` 根据 `Tag` 检查对应堆栈是否为空；非空时取出栈顶元素并移动栈顶。
4. 满栈或空栈时输出规定信息，并返回相应失败值。
