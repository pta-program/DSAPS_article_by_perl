## 6-3 求链式表的表长

- **分值：** 10分

## 题目描述

本题要求实现一个函数，求链式表的表长。

## 函数接口定义
```perl
# Perl 用哈希/数组引用模拟题目中的结点和容器类型。
use strict;
use warnings;

# length 与 Perl 内置函数同名，调用时使用 &length($head)。

sub new_node {
    my ( $data, $next ) = @_;
    return { data => $data, next => $next };
}
sub length;
```

其中`List`结构定义如下：

```perl
# List 是链表头结点的哈希引用；结点字段为 data 和 next。
```

`L`是给定单链表，函数`Length`要返回链式表的长度。

## 裁判测试程序样例
```perl
# 裁判样例：读取以 -1 结尾的链表数据并输出长度。
use strict;
use warnings;

sub read_list {
    my ( $head, $tail );
    while (<STDIN>) {
        for my $value ( split ) {
            last if $value == -1;
            my $node = new_node( $value, undef );
            if ($head) { $tail->{next} = $node }
            else       { $head = $node }
            $tail = $node;
        }
    }
    return $head;
}

sub main {
    print &length( read_list() ), "\n";
}
main();
```

## 输入样例
```text
1 3 4 5 2 -1
```

## 输出样例
```text
5
```

## 函数部分

```perl
# 沿 next 指针遍历，每访问一个结点计数一次，直到 undef 为止。
sub length {
    my ($head) = @_;
    my $count = 0;
    while ($head) { ++$count; $head = $head->{next} }
    return $count;
}
```

## 解题思路

链表没有连续的下标，长度只能通过遍历结点统计。设置计数器 `length`，从表头开始，每访问一个结点就加 1，直到指针为空。空链表不会进入循环，因此返回 0。

## 代码流程说明

1. 将计数器初始化为 0。
2. 判断当前指针是否为空；不为空则计数并移动到下一个结点。
3. 当前指针为空时，返回计数器。
